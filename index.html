    Preguntas frecuentes

    ¿Se suben mis archivos a algún sitio?

    No. Todo se procesa en tu navegador con la API Canvas: no hay servidor, ni cuentas, ni subidas. Las preferencias y el registro de copias se guardan solo en el almacenamiento local de este navegador.

    ¿Se puede quitar la marca de agua?

    Ninguna marca es imposible de quitar, pero esta lo pone muy difícil. El resultado se aplana en píxeles, así que la marca no es una capa separable del PDF. El texto ondulado con variaciones por letra, la trama de seguridad y el microtexto dificultan borrarla con herramientas automáticas.

    ¿Para qué sirve el código de rastreo?

    Es un código único que se imprime en cada copia. El registro de copias anota a quién diste cada código, así que si aparece una copia filtrada puedes saber de dónde salió. Usa un código distinto para cada destinatario.

    ¿Funciona sin conexión?

    Sí. Tras la primera visita, un service worker guarda la aplicación completa en caché. También puedes instalarla como app desde el navegador y usarla sin conexión.
